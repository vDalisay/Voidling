# Voidling Demo MVP

Godot 4.6 C# vertical slice.

Current demo: editable garden with LMB panning and Voidling pickup/renaming; Stats/DNA/Visual details; pannable genealogy; shop/training/breeding/hatching/inbreeding; one-player-vs-CPU race with Run hurdles, Ocean Pack swimming, elevated finite Fly glide with fall-to-Swim, Stamina/CHEER particles, Auto Finish, and podium results; persistent volume and race settings.

Run with `playgame.bat`. Build with `build.bat`. CI validates restore, C# build and Godot headless parsing.
