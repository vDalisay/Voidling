# Voidling Demo MVP

Godot 4.6 C# vertical slice for the initial raising, breeding and racing loop.

Current demo includes an editable garden with LMB panning, Voidling follow/pickup/renaming, non-overlapping modal UI, separate Stats/DNA/Visual details, pannable genealogy, shop/training/breeding/hatching/inbreeding, and a one-owned-Voidling-vs-CPU race with Run hurdles, Ocean Pack swimming, finite elevated Fly gliding/fall-to-Swim behavior, Stamina/CHEER particles, Auto Finish and aligned podium results. Settings persist volume and Auto Finish.

Use `playgame.bat` to run and `build.bat` to build. CI validates restore, C# build and Godot headless parsing.
